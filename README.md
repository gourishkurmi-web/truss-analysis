# 2D Roof Truss Member Force Analysis

This MATLAB project calculates the member forces and support reactions
of a simple 2D roof truss using the method of joints.

## Features

- Calculates member forces
- Determines tension and compression members
- Calculates support reactions
- Performs an equilibrium check
- Generates a 2D plot of the truss

## Method

The analysis is based on the equations of static equilibrium:

ΣFx = 0
ΣFy = 0

The resulting simultaneous equations are solved using MATLAB's
matrix left-division operator.

## Example

A 10 kN vertical load is applied at the top joint of a symmetric
triangular roof truss.

- MATLAB R2020a or later
